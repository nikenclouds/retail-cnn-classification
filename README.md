# Retail Product Classification

### Data Science Project For UTS

**Image Classification Using Convolutional Neural Network (CNN)**

*Computer Vision · Deep Learning · Retail Analytics*

---

🌸 **About This Project**

This project develops a Convolutional Neural Network (CNN)
to classify retail product images using image data and
category labels from a retail dataset.

🎀 **Objectives**

- Explore and prepare retail image data.
- Develop a CNN image classification model.
- Evaluate model performance using classification metrics.
- Generate product category predictions.

🩰 **Technology Stack**

Python · TensorFlow/Keras · NumPy · Pandas · Matplotlib · Scikit-learn


💗 **Evaluation Metrics**

Accuracy · Precision · Recall · F1-score · Confusion Matrix
